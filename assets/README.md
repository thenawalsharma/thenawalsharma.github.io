# Photos

Drop your images in this folder using these exact file names and they will appear on the site automatically (no code changes needed).

| File name | Where it appears | Recommended size |
| --- | --- | --- |
| `profile.jpg` | Big round portrait in the hero section | 800 × 800 px (square, face centred) |
| `photo-1.jpg` | Gallery tile 1 | 800 × 600 px (4:3) |
| `photo-2.jpg` | Gallery tile 2 | 800 × 600 px |
| `photo-3.jpg` | Gallery tile 3 | 800 × 600 px |
| `photo-4.jpg` | Gallery tile 4 | 800 × 600 px |
| `photo-5.jpg` | Gallery tile 5 | 800 × 600 px |
| `photo-6.jpg` | Gallery tile 6 | 800 × 600 px |
| `project-1.jpg` | ZST Application card | 800 × 400 px |
| `project-2.jpg` | Sirius CRM card | 800 × 400 px |
| `project-3.jpg` | Ratabase360 card | 800 × 400 px |
| `project-4.jpg` | Payment Request card | 800 × 400 px |
| `project-5.jpg` | PGM card | 800 × 400 px |
| `project-6.jpg` | Loyalty CRM card | 800 × 400 px |

Notes:

- JPG or PNG both work — just keep the `.jpg` file name (iOS converts screenshots to PNG, so rename if needed).
- Keep each file under ~300 KB so the page stays fast (`profile.jpg` under 150 KB is ideal).
- Any missing image is handled gracefully: the hero shows your initials and the gallery shows a placeholder icon.
- To change a gallery caption, edit the `data-caption="..."` value on the matching `<figure>` in `index.html`.
